Confidențialitate

Informare pentru vizitatorii Lexiconului agenților AI · Actualizată la 16 octombrie 2026

1. Cum funcționează site-ul

Lexiconul este un site static, găzduit prin GitHub Pages. În configurația sa actuală, codul propriu al lexiconului nu setează cookie-uri, nu conține formulare care să solicite date personale și nu integrează servicii de publicitate sau de analiză a comportamentului vizitatorilor.

Căutarea, navigarea între termeni și afișarea explicațiilor funcționează în browser, fără transmiterea căutărilor către un server al proiectului.

2. Preferința salvată în browser

Atunci când modifici opțiunea de afișare a explicațiilor „De ce contează?”, lexiconul reține alegerea în spațiul localStorage al browserului, prin cheia lexicon-show-why. Aceasta conține doar valoarea true sau false.

Preferința rămâne pe dispozitiv și poate fi ștearsă prin eliminarea datelor site-ului din setările browserului. Codul lexiconului nu o transmite către autor și nu o folosește pentru urmărirea vizitatorilor.

3. Găzduirea prin GitHub Pages

Site-ul este publicat pe infrastructura GitHub Pages, un serviciu operat de GitHub. Conform documentației GitHub Pages, când cineva vizitează un site Pages, adresa IP a vizitatorului este înregistrată și stocată de GitHub în scopuri de securitate, inclusiv dacă vizitatorul nu este autentificat.

Prelucrarea realizată de furnizorul de găzduire este descrisă în declarația de confidențialitate GitHub. Operatorul lexiconului nu primește prin codul site-ului o listă a adreselor IP ale vizitatorilor.

4. Legături către alte site-uri

Lexiconul include legături către lucrări, standarde, documentații și alte resurse externe. Acestea sunt accesate numai dacă alegi să le deschizi. După deschiderea unui asemenea link, site-ul respectiv poate prelucra date potrivit propriei politici de confidențialitate.

5. Semnalarea problemelor

Pentru corecturi sau întrebări despre site, poți folosi pagina publică GitHub Issues. Dacă alegi să publici un mesaj pe GitHub, informațiile transmise sunt gestionate și potrivit regulilor platformei.

6. Modificări

Dacă site-ul va integra ulterior statistici de trafic, formulare sau alte servicii externe, această informare va fi revizuită, iar cerințele privind consimțământul vor fi reevaluate înainte de activarea noilor funcții.
